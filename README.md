**A collection of self-contained modules for developing interactive JavaScript canvas programs.**

## Demo Programs
[Sketchpad](demo.html?sketchpad) - a sketchpad program leveraging the **Theatre** module.

[Orbit](demo.html?orbit) - an orbit simulation leveraging the **Velocity** module. (Keyboard Required)

[Aim](demo.html?aim) - a platformer leveraging the **Keyboard** module. (Keyboard Required)

[Hills](demo.html?hills) - a 3D scene leveraging the **Terrain** module.

[Layout](demo.html?layout) - a layout editor with collision detection leveraging the **Shapes** module.

[Chat](demo.html?chat) = a chatroom leveraging the **Messenger** and **Switchboard** modules. (Not Deployed)

[Scene](demo.html?scene) - an interative page leveraging the **Card** module.

## Modules

Card (In Development) - HyperCard inspired framework for interactive UI.

Keyboard - Keybind inputs.

Messenger - Client side socket handling.

PhysicsObject (In Revision) - Handles velocity upon collisions.

Shape - Collision detection for Rectangles, Circles, and Points.

Switchboard - Server side socket handling.

Terrain - Efficient 3D rendering for heightmaps.

Texture - Image and animation rendering.

Theatre - Responsive pixel canvas.

Velocity - Make things move!
